### 使用建议

1. 在需要替换的组件头部引入：
   ```ts
   import { useT } from '../lib/i18n'
   const t = useT()
   ```
2. 替换示例：
   - `title="举报"` → `title={t('post.report')}`
   - `'请输入提取密码'` → `{t('share.extractPassword')}`
   - `<span>{count} 个文件</span>` → `<span>{t('wallet.durationDays', { days: count })}</span>`
3. 对于带占位符的键，调用时传入对应 vars 对象。
4. `throw new Error('未登录')` → `throw new Error(t('errors.notLoggedIn'))` —— 但注意 lib/api.ts 中处于模块顶层，无法使用 hook，可以直接保留后端错误文案或使用 `messages['zh-CN'][key]` 直读。
